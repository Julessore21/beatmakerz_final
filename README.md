# Beatmakerz

Plateforme web de vente d'instrumentales construite avec [Next.js](https://nextjs.org/).

## Scripts

- `npm run dev` : démarre le serveur de développement.
- `npm run build` : compile l'application pour la production.
- `npm run start` : lance l'application compilée.
- `npm run lint` : exécute ESLint selon la configuration du projet.
- `npm run typecheck` : vérifie les types TypeScript sans générer de fichiers.

## Prérequis

- Node.js 18 ou supérieur
- npm 10 ou supérieur

## Installation

```bash
npm install
```

## Lancement en développement

```bash
npm run dev
```
